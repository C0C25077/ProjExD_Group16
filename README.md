# 工科大戦争
![ゲーム画面](fig/screen_shot.png)

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1

## 実行方法
"""
python nyanko_base.py
"""
* 画像は `fig/`、音は `sound/` フォルダに置く（ゲームのファイルと同じ場所）
* 素材ファイルが見つからない場合は、四角形の表示・無音のままゲームが動く

## ゲームの概要
* 右側の自陣からキャラクターを出撃させ、左側の敵陣を攻略するタワーディフェンスゲーム
* お金を使ってキャラクターを出撃させ、敵陣のHPを0にすれば勝利、自陣のHPが0になれば敗北
* 参考：スマートフォン[にゃんこ大戦争](PONOS)

## ゲームの遊び方
### 操作方法
| 操作 | 内容 |
|---|---|
| 数字キー 1〜7 / 画面下のボタンをクリック | キャラクターを出撃させる |
| `W` キー / `0` キー / 画面右下の「財布LV UP」ボタン | 財布をレベルアップする |
| 落ちてくるコインをクリック | コインをキャッチしてお金を増やす |
| 自陣の上の「準備OK!」をクリック | にゃんこ砲を発射する |
| `M` キー | BGM・効果音のミュートを切り替える |

### ゲームの流れ
1. 起動するとステージ（ノーマル／ハード）の選択画面が表示されるので、クリックで選ぶ
2. お金は時間とともに増える。お金が足りない間やクールダウン中は出撃できない
3. ゲーム開始から約20秒後にボスが出現する
4. 敵陣のHPを0にすれば勝利、自陣のHPが0になれば敗北

### お金を増やす方法
* **時間経過**：毎フレーム少しずつ増える（所持金には上限がある）
* **コイン**：約3.6秒ごとに空から落ちてくる。クリックでキャッチすると50円増える
* **財布レベルアップ**：所持金の上限と増加速度が上がる（最大レベル8、必要な費用はレベル×100円）
* コストが所持金の上限より高いキャラクターは出撃できないので、財布をレベルアップして上限を上げる

### キャラクター一覧
| キー | 名前 | コスト | 特徴 |
|---|---|---|---|
| 1 | ネコ | 50 | 基本のキャラクター |
| 2 | カバタンク | 100 | 体力が高い |
| 3 | 投げザル | 120 | 射程が長い遠距離攻撃 |
| 4 | キリン | 250 | 攻撃力が高い |
| 5 | ワニボンバー | 500 | 周囲の敵をまとめて攻撃する範囲攻撃 |
| 6 | ケサラン | 800 | 打たれ弱いが射程が非常に長く、敵をふっとばして足止めする |
| 7 | ドラゴン | 1000 | 空中を進み、範囲攻撃で敵を押し戻す。4回攻撃するごとに広範囲の爆波を放つ |

## ゲームの実装
### 共通基本機能
* 出撃システム(お金とクールダウン)、ユニットの移動、戦闘、城のHP、勝敗判定、UI表示

### 分担追加機能
* **お金上昇＆財布レベルアップ（担当：もろ）**
  * `Wallet` クラスを拡張し、財布レベル（`level`）、最大レベル（`max_level`）、費用計算（`get_level_up_cost()`）、レベルアップ処理（`level_up()`）を実装
  * レベルアップごとに、所持金の上限が +350、1フレームあたりの収入が +0.35 増える
  * 費用はレベル×100円。お金が足りないときや最大レベルのときは、ボタンがグレーアウトする
  * 画面右上のお金表示に現在のレベルを表示し、ボタンに操作キーと必要費用を表示する
* **キャラクター全般（担当：かわひら）**
  * `Unit` を継承したクラスで、攻撃方法の違うキャラクターを実装
    * `AreaUnit`：攻撃対象の周囲の敵も巻き込む範囲攻撃（ワニボンバー）
    * `ShooterUnit`：射程の長い遠距離攻撃（投げザル）
    * `StopperUnit`：攻撃した相手を一定時間動けなくする足止めの敵
    * `BossUnit`：HPが半分以下で怒りモードになり、強化されて手下を呼ぶボス
    * `WarshipUnit`：空中を進み、範囲攻撃と押し戻し、4回ごとの爆波を持つ（ドラゴン）
    * `KesaranUnit`：丸くて打たれ弱く、射程が長く、敵を押し戻して足止めする（ケサラン）
  * 押し戻し処理を関数 `push_back` にまとめ、性能データの `kind` からクラスを選ぶ `create_unit` で生成する
* **ステージ・ウェーブ管理（担当：りつき）**
  * ゲーム開始時のステージ（ノーマル／ハード）選択画面
  * ゲーム開始から一定時間（1000フレーム、約20秒）後のボス出現
* **画像、アニメ、BGM・効果音（担当：やくしじ）**
  * 四角形のキャラクターを画像に差し替え、歩行アニメ（2枚の画像を交互に表示）と攻撃ポーズを実装
  * 攻撃音、出撃音、勝利音、敗北音と、ループ再生するBGM
  * `M` キーでミュートを切り替える（`SoundManager` クラス）
  * 素材が見つからなくても、四角形と無音でそのまま動く
* **お金稼ぎミニゲーム＆にゃんこ砲（担当：こざわ）**
  * コイン：180フレーム（約3.6秒）ごとに画面上部のランダムな位置から落下し、クリックでキャッチすると50円増える。地面に着くと消える。コインをクリックしたときは、出撃ボタンなどの他の処理は行わない
  * にゃんこ砲：1000フレーム（約20秒）でチャージが満タンになり、自陣の上の「準備OK!」をクリックすると発射する。画面上のすべての敵に200ダメージを与え、紫色のビームを15フレーム表示する。発射後はチャージが0に戻る

### メモ
* ユニットの性能は `CAT_SPECS`、`ENEMY_SPECS` の辞書で管理する
* 新しい種類のキャラクターは、性能データに `kind` を書き、`UNIT_CLASSES` に対応するクラスを登録すると追加できる
* 関数・クラスには型ヒントとdocstringを付ける
