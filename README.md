### 分担追加機能
* 機能名（担当：名前）：説明
・追加機能１（もろ）：お金上昇＆財布レベルアップ
➡キーかボタンで所持金の上限と増加速度を強化。強化費用が上がり、最大レベルを設定する。UIにレベル表示
・追加機能１（もろ）：お金上昇＆財布レベルアップ
➡ キー入力やUIボタンクリックにより、お金の管理パラメータをリアルタイムで強化するシステム。
  **操作**: 
    `W` キー / `0` キー / 画面右下「財布LV UP」ボタン
  **仕様**:
    `Wallet` クラスを拡張し、財布レベル（`level`）、最大レベル（`max_level`）、強化費用計算（`get_level_up_cost()`）、レベルアップ処理（`level_up()`）を実装。
    レベルアップごとに「所持金上限（`+350`）」と「毎フレームの収入量（`+0.35`）」が増加。
    レベルに応じたコスト（レベル×100円）を設定し、所持金が足りない場合や最大レベル到達時はボタンがグレーアウトして発動を制限。
    画面右上のお金表示に現在のレベルを追記し、ボタン内に操作キーと必要コストを描画。

・追加機能２（かわひら）：キャラクター全般
➡範囲攻撃、遠距離攻撃、味方の足を止める敵、体力が大きいボス敵など。Unit を継承したクラスで作る

・追加機能３（りつき）：ステージ・ウェーブ管理
➡ステージ選択、敵の出現パターン（ウェーブ制）、一定時間後にボス登場、ステージごとに敵城のHPを変える

・追加機能４（やくしじ）：画像、アニメ、BGM・効果音
➡四角を画像に差し替え、歩行アニメ、攻撃時の効果音、BGM、ミュートキー。素材は自作かフリーのもの

追加機能５（こざわ）：お金稼ぎミニゲーム
➡画面上から落ちてくるコインをクリックでキャッチすると、お金が増えます。収入を待つだけでなく、操作で稼ぐ手応えが出ます。実装は Coin クラスのスプライトと衝突判定です。
