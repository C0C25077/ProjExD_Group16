#　工科大戦争

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1

## ゲームの概要
* 右側の自陣からキャラクターを出撃させ、左側の敵陣を攻略するタワーディフェンスゲーム
* 参考URL：[サイトタイトル](https://...)

## ゲームの遊び方
* 数字キー1〜3、または画面下のボタンのクリックでユニットを出撃させる
* お金は時間とともに増える。お金が足りない間やクールダウン中は出撃できない
* 敵陣のHPを0にすれば勝利、自陣のHPが0になれば敗北

## ゲームの実装
### 共通基本機能
* 出撃システム（お金とクールダウン）、ユニットの移動・戦闘、城のHP、勝敗判定、UI表示

### メモ
* ユニットの性能は `CAT_SPECS`、`ENEMY_SPECS` の辞書で管理する
* 関数・クラスには型ヒントとdocstringを付ける

README上の分担で、次の3点がぶつかる可能性がある。

１ボス敵：追加機能2の「ボス敵」と、追加機能3の「一定時間後にボス登場」が重なっています。ボスのクラスは追加機能2、出現のタイミングや出現パターンは追加機能3、と分けると安全です。

２お金まわり：追加機能1と5はどちらも Wallet を触ります。「収入を増やす操作は wallet.money に直接足さず、Wallet のメソッド経由にする」などを決めておくと、マージが楽になります。

３画像の差し替え：追加機能4は Unit の見た目（image）を変えます。追加機能2のボスは image を塗り直すので、どこで画像を作るかを相談してください。
