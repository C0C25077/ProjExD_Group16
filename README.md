# ProjExD_Group16
# 工科大戦争

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1

## ゲームの概要
* 右側の自陣からキャラクターを出撃させ、左側の敵陣を攻略するタワーディフェンスゲーム
* 参考：スマートフォンゲーム「にゃんこ大戦争」（PONOS）

## ゲームの遊び方
* 数字キー1～3、または画面下のボタンのクリックでユニットを出撃させる
* お金は時間とともに増える。お金が足りない間やクールダウン中は出撃できない
* 敵陣のHPを0にすれば勝利、自陣のHPが0になれば敗北

## ゲームの実装
### 共通基本機能
* 出撃システム（お金とクールダウン）、ユニットの移動・戦闘、城のHP、勝利判定、UI表示

### 分担追加機能
* 機能名（担当：名前）：説明
・追加機能１（もろ）：お金上昇＆財布レベルアップ
➡キーかボタンで所持金の上限と増加速度を強化。強化費用が上がり、最大レベルを設定する。UIにレベル表示

・追加機能２（かわひら）：キャラクター全般
➡範囲攻撃、遠距離攻撃、味方の足を止める敵、体力が大きいボス敵など。Unit を継承したクラスで作る

・追加機能３（りつき）：ステージ・ウェーブ管理
➡ステージ選択、敵の出現パターン（ウェーブ制）、一定時間後にボス登場、ステージごとに敵城のHPを変える

・追加機能４（やくしじ）：画像、アニメ、BGM・効果音
➡四角を画像に差し替え、歩行アニメ、攻撃時の効果音、BGM、ミュートキー。素材は自作かフリーのもの

追加機能５（こざわ）：お金稼ぎミニゲーム
➡画面上から落ちてくるコインをクリックでキャッチすると、お金が増えます。収入を待つだけでなく、操作で稼ぐ手応えが出ます。実装は Coin クラスのスプライトと衝突判定です。

仕様詳細
コインの生成

指定フレーム間隔（COIN_INTERVAL = 180：約3.6秒ごと）で1枚ずつ生成。

画面上部のランダムなX座標（50px ～ 画面幅 - 50px）から出現。

動作・挙動

画面下部（地面の高さ GROUND_Y）に向かって一定速度（1.5 ～ 3.0のランダム速度）で落下。

地面に到達すると自動的に消去（ヒットせず見逃した場合）。

クリック判定（キャッチ）

マウス左クリック時にコインの範囲内（collidepoint）であればコインを獲得。

1回のクリックでキャッチできるのは1枚のみ。

コインをキャッチした場合、出撃ボタンなどの他のクリック処理はキャンセルされる。

報酬

コイン1枚につき 50円 を所持金（wallet.money）に追加（上限 max_money を超えない範囲）。

にゃんこ砲機能
概要
時間の経過でゲージがチャージされ、満タン時に自陣（城）の上に表示されるボタンを押すことで、画面上のすべての敵ユニットにまとめて大ダメージを与える必殺技要素。

仕様詳細
チャージ仕様

max_charge（初期設定：1000フレーム）経過するとチャージ完了。

チャージ中は自陣の城の上に青色の進捗ゲージを表示。

UI表示（準備完了時）

チャージが満タンになると、自陣の城の上に黄色の「準備OK!」ボタンが表示。

発射・効果

「準備OK!」ボタンをマウス左クリックすると発射。

発射時、画面上に存在する全ての敵ユニットに即座に 200ダメージ を与える。

発射後、チャージ量は0に戻り、再チャージを開始。

ビーム演出（エフェクト）nyan

発射から15フレーム間、自陣から画面左端へ向かって貫く紫色の極太ビーム（半透明描画）を表示。
