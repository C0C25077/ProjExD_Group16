## ゲームの実装
### 共通基本機能
* 背景画像と主人公キャラクターの描画

### 分担追加機能
* 機能名（担当：名前）：説明
・追加機能１（もろ）：お金上昇＆財布レベルアップ
➡キーかボタンで所持金の上限と増加速度を強化。強化費用が上がり、最大レベルを設定する。UIにレベル表示

・追加機能２（かわひら）：キャラクター全般
➡範囲攻撃、遠距離攻撃、味方の足を止める敵、体力が大きいボス敵など。Unit を継承したクラスで作る

・追加機能３（りつき）：ステージ・ウェーブ管理
➡ステージ選択、敵の出現パターン（ウェーブ制）、一定時間後にボス登場、ステージごとに敵城のHPを変える

・追加機能４（やくしじ）：画像、アニメ、BGM・効果音
➡四角を画像に差し替え、歩行アニメ、攻撃時の効果音、BGM、ミュートキー。素材は自作かフリーのもの

追加機能５（こざわ）：お金稼ぎミニゲーム
➡画面上から落ちてくるコインをクリックでキャッチすると、お金が増えます。収入を待つだけでなく、操作で稼ぐ手応えが出ます。実装は Coin クラスのスプライトと衝突判定です。
